# Digital Agency Website

## 🚀 Project Overview
This is a **responsive Digital Agency website** built using **HTML, CSS, and Bootstrap**. The purpose of this project is to learn and practice Bootstrap's grid system, components, and responsiveness while building a modern website layout. This is a **frontend-only** project.

## 🎯 Features
- Fully **responsive** design
- **Sticky Navbar** for easy navigation
- **Hero section** with a call-to-action
- **Services section** showcasing agency offerings
- **Portfolio section** for projects display
- **Contact section** with a form
- Modern UI with Bootstrap components

## 🛠️ Technologies Used
- **HTML5** - Structure of the website
- **CSS3** - Styling and customizations
- **Bootstrap 5** - Grid system and UI components
